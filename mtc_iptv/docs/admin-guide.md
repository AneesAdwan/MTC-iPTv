# دليل المدير المختصر (§27 بند 12)

> كل الإدارة داخل برنامج Windows (قسم «الإدارة» في القائمة الجانبية). الدخول: البريد وكلمة المرور ثم رمز تطبيق المصادقة (MFA إلزامي).

## العمل اليومي (5 دقائق)

1. **لوحة المعلومات (A1):** نسبة نجاح التشغيل، الروابط المتعطلة، البلاغات، التنبيهات. كل بطاقة تفتح القائمة المفلترة.
2. **التنبيهات (A3):** عالج «الجديد»، ثم «تمّ الحل». المشكلة نفسها تبقى تنبيهًا واحدًا يزداد عدّاده.
3. **البلاغات (D6):** «جرّب» القناة، و«فحص الروابط»، ثم «تمّ الحل» أو أخفِ القناة.
4. **قيد المراجعة (D1):** القنوات الجديدة لا تُنشر قبل موافقتك.

## إضافة قنوات

| الطريقة | الشاشة | ملاحظات |
|---|---|---|
| قناة يدوية | B1 ← «إضافة قناة» | تُنشر فورًا، وحقولها محمية من الاستيراد |
| ملف M3U/CSV/JSON… | C1 الاستيراد | معاينة ← مطابقة ← الجديد يذهب للمراجعة، والموجود يُحدَّث دون لمس الحقول المحمية 🔒 |
| مصدر دوري | C3 المصادر | يُحدَّث تلقائيًا من المُجدوِل |
| iptv-org | C4 الموصلات | بحث واستيراد من المرجع |
| حساب Xtream | C1 ← Xtream | كلمة المرور محفوظة مشفّرة في Vault ولا تظهر |

**قواعد التحويل (C6):** «مجموعة Sport ← فئة رياضة» وغيرها تُطبَّق على كل استيراد.

## جودة الكتالوج

- **فحص الروابط (D4):** «يعمل» تعني ظهور صورة فعلًا (فحص تشغيل)، لا مجرد استجابة الخادم. عند الشك تظهر «غير حاسم»، لا «معطّل».
- **المكررات (D2/D3):** قارن ثم ادمج. الدمج قابل للتراجع من صفحة القناة.
- **الشعارات (D5)، الترقيم (B7)، التقسيمات (B5)، الرئيسية (B4).**
- **الدليل (E1–E3):** مصادر XMLTV وربطها بالقنوات ومعاينة.

## الإعدادات المركزية (تصل كل الأجهزة دون إصدار)

G1 الهوية · G2 الحسابات الاجتماعية وقنوات الدعم · G3 الافتراضيات والرقابة الأبوية · G4 المشغّل والفحص · G5 **الصيانة والإخفاء الفوري وإيقاف الميزات** · G6 الحد الأدنى والموصى به · F1 الإشعارات · F2 الإعلانات.

## النظام

- **المهام المجدولة (H2):** تعمل من برنامجك. أبقِه مفتوحًا أو في منطقة الإشعارات، وفعّل «البدء مع ويندوز».
- **النسخ الاحتياطي (H4):** مجلد متزامن مع OneDrive أو Google Drive، وعبارة مرور تحفظها أنت. **بدونها لا يمكن فتح النسخ.** الاستعادة تضيف وتحدّث فقط، ولا تحذف.
- **التدقيق (H3):** كل تغيير مع «قبل ← بعد».
- **الصيانة (H5):** منطقة الخطر تأخذ نسخة إلزامية قبل أي حذف.
- **التحليلات (I1):** من مشاهدات حقيقية فقط، مع تصدير CSV.
