# ADR-03: الخادم: Supabase

- **الحالة:** معتمد
- **التاريخ:** 2026-10-14
- **المسؤول:** أنيس عدوان

## السياق

القاعدة الحالية على Supabase وتعمل.

## القرار

Supabase مركزي + كتالوج محلي (Drift).

## البدائل المرفوضة

- VPS خاص: صيانة وأمان ونسخ علينا

## العواقب

نعتمد على خدمة خارجية؛ الخطة المجانية بلا نسخ احتياطي من Supabase.
