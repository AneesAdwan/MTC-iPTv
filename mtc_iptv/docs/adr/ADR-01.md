# ADR-01: تقنية الواجهة: Flutter

- **الحالة:** معتمد
- **التاريخ:** 2026-10-14
- **المسؤول:** أنيس عدوان

## السياق

نحتاج تطبيقًا واحدًا لـ Windows ثم Android (جوال وTV) وmacOS، بمشغّل لا تقيّده قيود المتصفح (AC3، HEVC، TS، CORS).

## القرار

Flutter / Dart لكل المنصّات.

## البدائل المرفوضة

- Electron/Tauri: محرّك المتصفح لا يشغّل AC3 وHEVC وTS بموثوقية
- C#/WPF: Windows فقط
- إبقاء React Native: لا دعم ناضج لسطح المكتب

## العواقب

إعادة كتابة كاملة؛ لغة جديدة (Dart)؛ قاعدة كود واحدة.
