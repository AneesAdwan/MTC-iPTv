# ADR-12: توقيع Windows (Authenticode)

- **الحالة:** مؤجل
- **التاريخ:** 2026-10-14
- **المسؤول:** أنيس عدوان

## السياق

التوقيع يزيل تحذير SmartScreen.

## القرار

مؤجل بقرار المالك (D-07).

## البدائل المرفوضة

- Azure Trusted Signing
- شهادة تقليدية

## العواقب

تحذير SmartScreen عند التثبيت الأول؛ التحديثات محمية بـ EdDSA.
