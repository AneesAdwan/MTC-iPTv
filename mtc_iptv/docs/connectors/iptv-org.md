# موصل iptv-org

| البند | التفاصيل |
|---|---|
| **الاسم والغرض** | `iptv-org` — بيانات القنوات (المعرّفات الموحّدة، الأسماء البديلة، الدولة، الفئات، الشبكة، الموقع) وروابطها وشعاراتها. **مصدر المعرّفات الموحّدة** وأساس المطابقة (§11.1، المرتبة 2) |
| **التوثيق الرسمي** | https://github.com/iptv-org/api — نقاط النهاية: `https://iptv-org.github.io/api/channels.json`، `streams.json`، `logos.json`، `categories.json` |
| **الترخيص وشروط الاستخدام** | المستودع بترخيص **Unlicense** (ملكية عامة). آخر مراجعة: 2026-10-16. **وجود رابط في iptv-org ليس دليلًا على حق إعادة توزيعه** (§13.3-8): القنوات الجديدة تمرّ دائمًا بالمراجعة |
| **مستقل أم مشتق** | مجتمعي، يجمع من مصادر متعددة؛ لا يُفترض استقلاله عن قوائم M3U العامة الأخرى (§13.3-5) |
| **المصادقة والأسرار** | لا توجد |
| **حدود الطلبات** | لا حد معلن (GitHub Pages). نطبّق: جلب يدوي عند الطلب فقط، 3 ملفات بالتوازي، مهلة 120 ث، حد 80MB لكل ملف |
| **سياسة إعادة المحاولة** | لا إعادة تلقائية؛ يعيد المدير المحاولة يدويًا. الأخطاء تُعرض كما هي |
| **شكل البيانات وإصداره** | `schemaVersion = 1`: `channels.json` (id، name، alt_names، network، country، categories، is_nsfw، closed، website)، `streams.json` (channel، feed، url، title، quality، user_agent، referrer)، `logos.json` (channel، feed، url). **كشف التغيّر:** إن لم يكن أعلى الملف قائمة، أو تعذّر تحليل > 30% من السجلات ← `ConnectorShapeChanged` ولا يُستورد شيء |
| **قواعد الجلب والتحديث** | جلب كامل عند الطلب (لا يوجد جلب تفاضلي). البيانات في ذاكرة البرنامج فقط |
| **قواعد المطابقة** | `tvg-id = channels.id` (المرتبة 2)، ثم نفس خط الاستيراد (§11.1): الرابط، معرّف EPG، الاسم + الدولة كاقتراح فقط |
| **قواعد الحذف** | لا شيء يُحذف أبدًا بسبب اختفاء قناة أو رابط من iptv-org (§10.4) |
| **السجلات الناقصة أو غير الصالحة** | قنوات بلا `id` أو `name` تُتجاهل (تُعدّ فشلًا)؛ روابط بلا `channel` لا تُربط؛ قنوات الكبار (`is_nsfw`) والمغلقة (`closed`) تُستبعد |
| **إسناد البيانات** | مرتبة «موصل موثوق» (4) في §11.2، تحت اليدوي والقواعد |
| **السجلات ومؤشرات الصحة** | `healthCheck` = `categories.json` يعيد 200. القبول يُسجَّل في `task_runs` (المهمة `sources`) كأي استيراد |
| **الاختبارات** | وحدة: `packages/mtc_core/test/iptv_org_test.dart` (عيّنات محفوظة، شكل متغيّر، ملف فارغ). تكامل حي: جُرّب يدويًا 2026-10-16 (29,784 قناة، 10,204 بروابط، 312 عربية بروابط) |
| **التعطيل والإصلاح** | الموصل لا يكتب شيئًا بنفسه؛ يمرّ دائمًا عبر معاينة الاستيراد. تعطيله = عدم فتح الشاشة؛ لا أثر على الكتالوج |
