### ملاحظات للتنفيذ من اختبار سطح المكتب
- `tray_manager` 0.8 غيّر واجهته: التطبيق الحقيقي يستخدم الواجهة الأصلية لا `legacy.dart`.
- توقيع التحديثات على Windows = **DSA** (`dsa_priv.pem`)، يُحفظ خارج المستودع مع نسخة احتياطية مشفّرة.
- دوال PowerShell تُرجع كل مخرجات الأوامر: سكربتات البناء تُوجّهها إلى `Out-Host`.
- سكربتات `.ps1` تُكتب ASCII (أو UTF-8 مع BOM) لأن Windows PowerShell 5 يقرأ UTF-8 بلا BOM خطأً.
