# 4.1 الاستيراد
- **شو بتعمل:** بتجيب قنوات من ملف M3U أو رابط قائمة أو حساب Xtream.
- **كيف:**
  1. **ارفع ملف** (سحب وإفلات) أو الصق رابط أو بيانات Xtream.
  2. **التحليل:** شو بالملف (عدد، صيغة، مشاكل).
  3. **المعاينة:** كل سطر شو رح يصير فيه: **جديدة** (← مركز القرارات)، أو **رابط إضافي لقناة موجودة**، أو **موجود أصلًا**، أو **فاشل**، ومع كل واحد «ليش».
  4. **قبول:** ولا شي بينكتب قبل هالخطوة.
- **ورا الكواليس:**
  - الملف بيترفع للخادم، والمطابقة بتصير هناك، فما بينزل الكتالوج على جهازك.
  - كلمات Xtream بتنحفظ مشفّرة بالخزنة.
- **المشاهد:** ولا شي بيطلعله قبل ما تنشره من مركز القرارات.
- **التراجع:** «تراجع عن هالدفعة» بيشيل كل اللي انضاف فيها.
