# 3.3 مكرر محتمل

- **شو يعني:** قناتين أو أكثر بنفس الاسم والدولة
- **من وين بيجي:** فحص يومي بالخادم
- **القرارات:** **قرار لكل قناة:** إبقاء · إبقاء ونشر · إخفاء · ادمج روابطها بقناة · سلة · «ليست مكررة»

> كل بطاقة بمركز القرارات فيها: القناة، المشكلة بجملة («ليش هي هون»)، والدليل، وأزرار القرار. بعد كل قرار بيطلع شريط «تمّ · تراجع».
