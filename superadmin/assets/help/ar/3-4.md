# 3.4 لا تعمل

- **شو يعني:** كل روابط القناة فشلت بالفحص أو عند المشاهدين
- **من وين بيجي:** فحص الخادم + قياس المشاهدين
- **القرارات:** جرّب · أعد الفحص · سيرفر بديل · عطّل الرابط · أخفِ القناة

> كل بطاقة بمركز القرارات فيها: القناة، المشكلة بجملة («ليش هي هون»)، والدليل، وأزرار القرار. بعد كل قرار بيطلع شريط «تمّ · تراجع».
