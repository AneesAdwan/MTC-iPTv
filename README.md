# MTC-iPTv

منصة بث مباشر لآلاف القنوات التلفزيونية من روابط عامة (مصدرها [iptv-org](https://github.com/iptv-org/iptv)).
الموقع ملفات ثابتة (HTML/CSS/JS) يعمل على GitHub Pages، وقاعدة البيانات على Supabase.

- **الموقع** `/`: مشاهدة فقط بأسلوب التلفاز. يتضمن الدول والفئات واللغات والسيرفرات، والمفضلة وآخر ما شوهد، والبحث بالاسم أو برقم القناة.
- **لوحة الإدارة** `/asadmin/`: قيد المراجعة، القنوات وروابطها، فحص الروابط، المكررات (مع مقارنة جودة البث)، البلاغات، المصادر، التقسيمات، الإعدادات العامة، والنسخ الاحتياطي والاستعادة.

> **بوابة المراجعة:** أي قناة تُضاف لقاعدة البيانات — بأي طريقة (ملف SQL، استيراد M3U، استعادة نسخة، نسخة الديمو) — تدخل «قيد المراجعة» ولا تظهر للمشاهدين حتى يفحصها المدير ويوافق عليها. الاستثناء الوحيد: القناة التي يضيفها المدير يدويًا من اللوحة.

## إعداد قاعدة البيانات (من الصفر)

1. في Supabase افتح **SQL Editor** وشغّل `supabase/01_schema.sql`.
   ينشئ الملف الجداول والصلاحيات والدوال، ويضيف 250 دولة و120 لغة و28 فئة.
   ⚠️ يحذف جداول MTC القديمة، لكنه لا يمسّ حسابات المشرفين ولا إعدادات الموقع.
2. شغّل ملف البيانات `supabase/02_data.sql` في استعلام جديد
   (5,241 قناة و6,828 رابط بث، مرتبة حسب الدولة — الدول العربية أولًا). تدخل كلها «قيد المراجعة».
   بديل بدون SQL: من اللوحة ← النسخ الاحتياطي والصيانة ← **استعادة نسخة الديمو** (نفس المحتوى من `data/demo.json`).
3. أنشئ حساب المشرف من **Authentication → Users → Add user**، ثم شغّل:
   ```sql
   insert into public.admin_users(user_id)
     select id from auth.users where email = 'YOUR_EMAIL@example.com';
   ```
4. عطّل التسجيل العام من **Authentication → Sign In / Providers**، بإيقاف خيار «Allow new users to sign up».
5. من اللوحة ← **قيد المراجعة** ← «فحص القنوات المعلّقة»، ثم وافق على «الجاهزة للنشر» (المكررة والمعطّلة والناقصة مفصولة في تبويبات).
6. ضع رابط المشروع والمفتاح العام (anon / publishable) في `config.js`.
   لا تضع مفتاح `service_role` أو `sb_secret_…` في أي ملف داخل المشروع.

## فحص الروابط والقنوات المكررة

- **فحص الروابط**: النتائج في تبويبات (معطّلة، لم تُفحص، بطيئة، تعمل، معطّلة يدويًا) مع إعادة فحص أو تعطيل أو تفعيل أو حذف لكل رابط أو لمجموعة أو للتبويب كله. الرابط المعطّل يدويًا يبقى محفوظًا ولا يستخدمه المشغّل.
- **القنوات المكررة**: قارن بينها؛ إن كان البث نفسه فادمج أو أخفِ أو احذف، وإن كان بث كل قناة مختلفًا فاختر «ليست مكررة» لتبقى القنوات كلها دون أن تُكشف كمكررة مرة أخرى.

## النسخ الاحتياطي والاستعادة

من اللوحة ← **النسخ الاحتياطي والصيانة**:
- **تنزيل نسخة احتياطية**: ملف JSON واحد فيه القنوات والروابط والمصادر والدول والفئات واللغات والإعدادات والبلاغات (بدون حسابات المشرفين).
- **استعادة نسخة**: يستبدل البيانات الحالية بمحتوى الملف، بعد تنزيل نسخة من الوضع الحالي تلقائيًا. القنوات المستعادة تدخل «قيد المراجعة».
- **استعادة نسخة الديمو**: يحمّل مكتبة القنوات الجاهزة ويبدأ فحصها فورًا قبل النشر.

## الإعدادات العامة

من اللوحة ← **الإعدادات العامة**: اختيار قناة «يعرض الآن» في الرئيسية، واسم المطوّر وحساباته (يكفي اسم المستخدم فقط) التي تظهر في تذييل الموقع.

## تحديث بيانات القنوات

لإعادة توليد ملف البيانات `02_data.sql` ونسخة الديمو `data/demo.json` من أحدث بيانات iptv-org، مع فحص كل رابط من جديد:
```bash
node supabase/generate_data.mjs            # تنزيل + فحص (عدة دقائق)
node supabase/generate_data.mjs --no-check # بدون فحص
```
يمكنك أيضًا الإدارة كاملة من اللوحة: **مصادر البث ← تحديث**، ثم **فحص الروابط ← تنظيف**.

## التشغيل محليًا

```bash
npm run dev
```
ثم افتح http://localhost:5173 (ولوحة الإدارة على http://localhost:5173/asadmin/). لا يحتاج `npm install`.

## النشر على GitHub Pages

```bash
git init && git add . && git commit -m "MTC-iPTv"
git branch -M main
git remote add origin https://github.com/USER/REPO.git
git push -u origin main
```
بعدها من إعدادات المستودع: **Settings → Pages → Source: Deploy from a branch → main / (root)**.

> يمنع المتصفح تشغيل روابط `http://` على صفحة `https://`، لذلك يتجاهلها الاستيراد. ويتجاهل أيضًا الروابط التي لا تسمح بالتشغيل من موقع آخر (CORS).
