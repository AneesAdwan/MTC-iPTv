# MTC-iPTv

**منصّة بثّ القنوات التلفزيونية المباشرة**

[مشاهدة الموقع المباشر](https://aneesadwan.github.io/MTC-iPTv/)

</div>

---

MTC-iPTv منصّة عربية لمشاهدة القنوات التلفزيونية المباشرة من مختلف دول العالم،
بواجهة عصرية تدعم العربية بالكامل وتعمل على الهاتف والحاسوب.

## المزايا
- تصفّح القنوات حسب الدولة والفئة واللغة
- بحث سريع ومشغّل بثّ مباشر
- قائمة المفضلة والقنوات المُضافة حديثًا
- تصميم متجاوب يدعم العربية (RTL)

## التقنية
موقع ويب ثابت (HTML / CSS / JavaScript) يعمل على GitHub Pages.
